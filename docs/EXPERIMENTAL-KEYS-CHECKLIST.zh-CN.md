# 实验键逐项验证清单（v1.5 L）

这些键来自公开的 MobileGestalt 工具报告（GestaltX / Nugget 生态），**本机未验证**。App 里统一按值 `1` 写入，并在「实验功能（未验证）」分组中默认折叠、全部标为高风险。

逐项验证的目标不是"开得越多越好"，而是记录**每个键在自己机型上到底改变什么**，并把不生效或有害的键从清单里划掉。

## 0. 通用前置

1. 先在 Tools → 备份里**手动备份一份**（自动备份保留 20 份，手动备份不会被清理）。
2. 记录当前状态：关于本机型号、Face ID 可用性、Wi-Fi、相机、电池耗电。
3. 一次只开**一个**键，写入 → respring → 观察 → 记录 → 关闭该键（写回默认）→ respring。
4. 每轮结束用「还原官方身份」确认身份没被污染（实验键理论上不碰身份键）。
5. 出现白苹果/卡死时的回滚路径：App 每次写前自动备份，可在恢复页选最近一次自动备份整体还原；实在进不去系统则用 iLoader 重刷。

## 2. 记录模板

每个键验证后按下面格式追加到本节（或写在备份备注里）：

```
### 键名 / 哈希
- 机型：iPhone 17 Pro（iPhone18,1），系统：iOS 26.x
- 写入时间：2026-11-12 14:03
- 观察结果：设置里出现/未出现 XXX
- 结论：生效 / 无效 / 有副作用（说明）
- 副作用：耗电明显 / 发热 / 某项功能失效
- 后续：保留默认关闭 / 建议永久移除该键
```

## 3. 已知风险与不纳入的键

- **PWM / DisplayPort 类键**：部分面板上可能导致黑屏，未纳入实验分组。
- **AOD Flipbook / 数量**（`aoJSd/MXk7M40NgXTM6x+g`、`qqrspu7CpuPdZwSDxNY+Fg`）：语义不明（计数型而非布尔），未纳入。
- **端侧 Siri / 音频智能 / 翻译**：通常需要多个键 + 区域语言包同时满足，单独写一个键很可能"无变化"，这不等于键错，而是条件不足；记录时要注明。
- **iOS 26.2+ 收紧了 MobileGestalt 写入**：若写入成功但重启后值回退，说明该键在当前系统版本已不可写，直接标注"系统已封堵"。

## 4. 验证完成后的处理

- 全部无效或副作用明显 → 整组从 App 移除（`GestaltTweakCatalog` 删除对应定义与 `GestaltTweakID` case）。
- 个别生效 → 把该键从 `.experimental` 提到正式分类、去掉"未验证"标注、按实际语义重写 `detail`。
- 生效但风险高（烧屏、耗电）→ 保留在实验组，`detail` 中写明实测副作用。
